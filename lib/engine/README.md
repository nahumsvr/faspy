# Motor de simulación · P1

Funciones puras de validación, scoring y factoraje. Reciben datos por parámetros y
retornan resultados tipados; sin fetch, reloj, números aleatorios, base de datos ni
estado global. Esta entrega implementa únicamente el caso sintético acordado y no
extrapola umbrales ni fórmulas a otras entradas. La latencia de 700 ms vive en el
handler `/api/emitir-factura`.
