# Motor de simulación · P1

Funciones puras de validación y scoring. Reciben datos por parámetros y retornan
resultados tipados; sin fetch, reloj, números aleatorios, base de datos ni estado global.
Las reglas de negocio y umbrales deben acordarse antes de implementarlos.
La latencia de 700 ms corresponde al futuro handler `/api/emitir-factura`, no al motor.
